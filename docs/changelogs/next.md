# Next release

- Rebuilt on v1.1.1 as a Stonecutter multiloader project: Fabric and NeoForge from the same sources.
- Supports Minecraft 1.21.1 to 26.3 (NeoForge: no 1.21.6, 1.21.7, 1.21.9, never released upstream).
- From 1.21.6 the mod personalises Mojang's locator bar instead of adding its own; no server mod or network needed.
- Before 1.21.6 the mod keeps its own bar. With the mod on the server every player is shown; otherwise only players in render distance.
- New config screen; fixes the blurry screen caused by rendering twice.
- Settings screen shows the active mode.
